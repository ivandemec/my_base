# Grice's Razor

## Definition
> Conversational implications are preferred over assuming semantic context changes.

## Overview
Proposed by linguist Paul Grice, this razor states that when interpreting a speaker’s words, one should assume they are using words according to everyday conversational norms before concluding they are using a specialized, hidden, or completely new meaning. It prevents over-interpreting everyday language.
